Set up in any session

Clone my repo and run the bootstrap: it installs the extras, checks every source live, and prints the import line. kit.help() lists every call; kit.sources() prints a Sources list of what the session used.

git clone --depth 1 https://github.com/fortniticusIII/claude /home/claude/claude
bash /home/claude/claude/bootstrap.sh
import sys; sys.path.insert(0, "/home/claude/claude"); import kit
from kit import scholar, data, web, lookup, qa

Before publishing any page: python3 -m kit.qa page.html renders it at phone and desktop widths in both themes and flags overflow, script errors, contrast, tap targets and artifact-contract breaks, and lists every figure on the page to check against its source.
